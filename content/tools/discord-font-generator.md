### What you're actually copying

## What font does Discord use?

Discord's interface font is gg sans, a typeface made for Discord. It replaced Whitney, the font Discord had used since launch, at the end of 2022, and it's used across the desktop app, mobile apps and website.

### You can't change the Discord text font

There's no setting that swaps gg sans for another typeface, for you or for anyone reading your messages. Discord's appearance settings let you scale the chat text size, but the font stays the same.

### Why copied styles still show up

Styled text from this generator isn't a font, so Discord doesn't need to support it. ## Native markdown or Unicode: which to use

### Use markdown in messages

In chat messages, Discord's own formatting is the better choice. Wrap text in `**double asterisks**` for bold, `*single asterisks*` for italic, `__double underscores__` for underline, `~~tildes~~` for strikethrough and backticks for `code`. Recent versions also support headings with `#`. Markdown stays searchable and readable by screen readers. See Discord's [markdown guide](https://support.discord.com/hc/en-us/articles/210298617).

### Use Unicode where markdown isn't rendered

Markdown symbols show up literally in places like your display name, server nickname, custom status, server name, role names and channel names. That's where a styled Unicode string is the only way to get a bold or decorative look.

### Places Unicode won't work

Your username can only use lowercase letters, numbers, underscores and periods (2–32 characters), so styled characters aren't accepted there. Keep it plain and put the style in your display name instead.

## Where styled text fits on Discord

### Display name and server nicknames

Display names allow up to 32 characters, and styled characters count toward that. Server nicknames let you use a different look in each server.

### Custom status and About Me

A custom status can be 128 characters and your About Me 190. A short styled tagline in either one stands out on your profile card. Want ideas for what to write? See [how to write a Discord bio](/blog/discord-bio) or try the [Discord bio generator](/tools/discord-bio-generator).

### Server, category, role and channel names

Server names run 2–100 characters. Styled category headers like "𝕀ℕ𝔽𝕆" or role names like "🅼🅾🅳" help members scan the sidebar. Some channel name styles may be altered by Discord, so check the result after saving.

## Best practices for Discord

### Make names easy to mention

When a display name or nickname is fully styled, other members can't easily type it to @mention you, and moderators may have trouble finding you in the member list. Many servers ask members to use a mentionable name, and some have bots that reset styled nicknames. Read the server rules first.

### Style labels, not information

Channel names like "📢 𝐚𝐧𝐧𝐨𝐮𝐧𝐜𝐞𝐦𝐞𝐧𝐭𝐬" look tidy, but screen readers may spell them out letter by letter. Keep at least the key word recognizable, and avoid styling rules or instructions that people need to understand.

### Test on mobile

Some decorative characters render as empty boxes on older phones. Preview your server sidebar from the mobile app before you rename every channel.

### Stay within the limits

Use the [Discord character counter](/tools/discord-character-counter) to check messages, About Me, display name and status lengths before you paste.

## Frequently asked questions

### How do I change my font on Discord?

Discord doesn't let you change the app font for others. You can format messages with markdown, or paste Unicode look-alike characters from this generator into your display name, status or server labels.

### How do Discord fonts copy and paste into a name or bio?

Type your text above, tap a style to copy it, then open **User Settings → Profiles** and paste it into your display name or About Me. For one server only, paste it into your server nickname instead.

### Can I use fancy fonts in my Discord username?

No. Usernames only allow lowercase letters, numbers, underscores and periods. Put the styled text in your display name or a server nickname instead.

### Why do some members see boxes instead of my name?

Their device lacks a font with those characters. Bold, italic and double-struck styles are widely supported, while squared or rare script letters fail more often.

### Is markdown better than Unicode for bold messages?

Yes, in messages. Markdown bold is real formatting, so search and screen readers handle it properly. Use Unicode only where markdown isn't rendered.

### Is this Discord font generator safe to use?

It runs entirely in your browser, needs no sign-up, and doesn't send your text anywhere. It doesn't connect to your Discord account.

### Can bots read styled text?

Bots receive the actual Unicode characters, so commands or keyword filters written for plain letters won't match styled text. Keep bot commands plain.

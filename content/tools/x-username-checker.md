## X username rules at a glance
An X username (still called a Twitter handle by most people) has to be 4 to 15 characters long and can only use letters, numbers and underscores. This X username checker tests a handle against those rules as you type and, when it passes, gives you a button that opens x.com/yourhandle so you can see whether an account already has it.

| Rule | What X allows (at the time of writing) | Checked here |
|---|---|---|
| Length | 4–15 characters | Yes |
| Characters | Letters A–Z, numbers 0–9 and underscores | Yes |
| Spaces | Not allowed | Yes |
| Periods, hyphens, emoji, accents | Not allowed | Yes |
| Capital letters | Allowed, but not unique: @PixelStudio and @pixelstudio are the same handle | Shown as typed |
| Words like "Twitter" or "Admin" | Blocked by X | No, X's form decides |
| Already taken | Can't be claimed | Profile link only |

## What this Twitter username checker does (and what it can't)
The checker answers the question you can answer without X's help: does this handle follow the format X accepts? It removes a leading @ and any spaces around the name, measures the length, and lists every rule the name breaks, in plain words such as "Too long: 21 characters, the limit is 15."

It can't tell you for certain that a handle is free. X doesn't offer a public availability check, and accounts that are suspended, deactivated or locked can still hold a name even when their profile looks empty. What the tool gives you instead is a one-tap link to the profile URL. If a profile opens, the name is taken. If X says the account doesn't exist, the name is worth trying, and the sign-up form or the username field in your settings gives the final answer.

Everything runs in your browser. The names you type aren't sent to a server or saved, and the profile button is an ordinary link to x.com.

## What the X handle checker tests
### Length: 4 to 15 characters
New X usernames need at least 4 characters and can't go past 15. That's tight compared with Instagram's 30 or TikTok's 24, so a handle that works elsewhere often won't fit here. The checker shows the length as a count out of 15, so you can see how many characters you have to trim. Some very old accounts have handles shorter than 4 characters, but X doesn't let anyone register new ones that short.

### Letters, numbers and underscores only
Underscores are the only symbol X allows. A period, hyphen, apostrophe, ampersand, emoji or accented letter fails the check with "Only letters, numbers and underscores are allowed." If you're bringing over an Instagram handle like golden.hour, the usual fix is golden_hour or goldenhour.

### No spaces
A space anywhere in the name fails the check. Your display name, the bold name above your @handle, can have spaces; the handle itself can't.

### Tips for names with no letters
A handle made only of numbers and underscores is allowed, but hard to find and remember. If you type one, the checker adds a tip suggesting at least one letter. It's advice, not a rule, so the name still passes.

### Close valid variations
Whenever you type a name, the checker suggests up to 12 variations that already pass X's rules, such as pixelstudio_, thepixelstudio, pixelstudiohq or realpixelstudio. If your first choice is taken, they're a quick way to stay close to it. Suggestions use lowercase letters, numbers and underscores, and long names are shortened first so the additions still fit within 15 characters.

### Check a list of handles
Switch to **Check a list** and paste up to 200 names, one per line or separated by commas. Duplicates are dropped, each name is marked as following the rules or shows the first rule it breaks, and every valid name links to its x.com profile. A button copies only the valid ones, so you can paste a clean shortlist into a note or a message to your team.

## How to check if an X username is available
1. **Type the handle you want.** Leave out the @, or paste it with the @; the checker removes it either way.
2. **Read the format result.** "Follows X's rules" means it can be registered if nobody holds it. "Not allowed" comes with the reason, such as a period or a 16th character.
3. **Open the profile.** Tap the **Open x.com/…** button. If a profile loads, someone has the name. If X says the account doesn't exist, it may be free. If you're signed out, X may ask you to log in before it shows the page.
4. **Try a variation if needed.** Pick one of the suggested variations, or paste your shortlist into **Check a list** and open the profile links one by one.
5. **Claim it on X.** On a new account, enter it during sign-up. On an existing one, go to Settings, then Your account, then Account information, then Username (menu labels change between app versions). X tells you as you type whether the name is available, and that's the definitive check.

## Best practices for picking an X handle
### Keep it short enough to type
Fifteen characters is the ceiling, not the target. Shorter handles leave more room in replies, because every reply and mention includes the @handle, and they're easier to type on a phone.

### Use the display name for the details
Your display name can hold spaces, capitals and up to 50 characters, so it can carry what the handle can't, like "Riverside Bakery · Portland". Keep the handle clean and put the description in the name and bio. The [X bio generator](/tools/x-bio-generator) helps with the 160-character bio, and the [X name generator](/tools/x-name-generator) gives display name and handle ideas if you're starting from nothing.

### Avoid lookalike characters
Mixing the letter O and the number 0, or l and 1, makes a handle easy to mistype and easy to impersonate. If your preferred handle is taken, a clear modifier (hq, shop, studio, your city) is better than a near-copy.

### Know what the checker doesn't test
X also blocks some words, such as "Twitter" and "Admin", and names that impersonate others. Those rules aren't in this checker, because X can change them at any time; its sign-up form is the authority. The checker also can't see names held by suspended or deactivated accounts.

### Don't trust tools that promise more
No website can see X's private username database. A tool that asks for your X password or claims to reserve a handle for you can't do what it says. This checker never asks you to sign in.

## Frequently asked questions
### Can this X username checker tell me if a handle is available?
Not with certainty. It checks the handle against X's rules and opens the profile so you can see whether an account uses it. X's sign-up form or the username field in your settings gives the final answer.

### How many characters can an X username have?
An X username can have 4 to 15 characters at the time of writing. Older accounts may have shorter handles, but new ones need at least 4.

### Is a Twitter username checker the same as an X username checker?
Yes. Twitter became X, and the username rules didn't change with the rename. Your @handle works the same way, and twitter.com profile links now redirect to x.com.

### Can an X username have a period or a hyphen?
No. Only letters, numbers and underscores are allowed. Replace a period or hyphen with an underscore, or remove it.

### Are X usernames case-sensitive?
No. Capitals are shown the way you typed them, but @PixelStudio and @pixelstudio count as the same handle, so you can't register one if the other exists.

### Why does a profile show nothing, but X says the name is taken?
The name probably belongs to a suspended or recently deactivated account, or X reserves it. Those names stay unavailable even though no active profile appears.

### Can I check several X handles at once?
Yes. Switch to **Check a list** and paste up to 200 names. The checker marks which follow X's rules, links each valid one to its profile, and copies the valid ones for you.

### Does the checker save the handles I type?
No. It runs in your browser, and nothing you type is uploaded or stored.

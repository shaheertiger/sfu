## What makes a good Discord name
Discord gives you three names to think about: a unique lowercase **username**, a **display name** friends see in chats, and, if you run a community, a **server name**. A good username is easy to share in a friend request; a good server name tells people what they're joining. Type a keyword above to get 30 ideas.

### Usernames are unique now
Discord retired the old "name#1234" tags, so each username can belong to only one person. Short, common words were claimed early. Expect to add a twist: a second word, a number with meaning, or an underscore or period in the middle.

### Display names do the talking
In servers, most people see your display name rather than your username. It can include spaces, capitals and emoji, so it's the place for "Lena the Healer" while your username stays something tidy like "lenaheals".

### Server names set expectations
A server name appears in invites, in the server list and in Discord's server discovery for eligible communities. "Cozy Builders Club" signals a relaxed building community; "MINECRAFT HARDCORE PVP" signals something else entirely. Pick words that attract the members you want.

## How to use the Discord name generator
One keyword can give you a username, a display name and a server name.

### Step by step
1. **Type a keyword.** A game, class, hobby or nickname: "healer", "lofi", "jun".
2. **Pick a style.** Gaming and cool suit players and clans; aesthetic suits art and music servers; funny fits friend groups; professional and minimal suit study and developer communities.
3. **Copy usernames.** Ideas meant as usernames use only lowercase letters, numbers, underscores and periods, between 2 and 32 characters. Tap to copy.
4. **Use the rest as display or server names.** Longer ideas with capitals and spaces make good display names and server titles.
5. **Regenerate and check.** The generator can't see Discord's users or servers. Discord checks username availability when you change it in **User Settings > My Account**.

### Matching names across a group
Running a clan? Generate with a shared keyword ("ember") and give each member a related name: "ember.scout", "ember_tank", "emberwitch".

## Discord name rules and limits
Values at the time of writing; see [Discord's support site](https://support.discord.com) for the latest.

| Field | Limit | Allowed characters |
|---|---|---|
| Username | 2–32 characters | Lowercase a–z, 0–9, underscores, periods |
| Display name | 32 characters | Most characters, including spaces and emoji |
| Server name | 2–100 characters | Most characters, including spaces and emoji |
| About Me | 190 characters | Text, emoji, markdown |
| Custom status | 128 characters | Text and emoji |

### Period placement
Discord allows periods in usernames but not two in a row, so "ember..scout" won't be accepted while "ember.scout" will.

### Server names don't need to be unique
Any number of servers can share a name, so a distinctive one helps yours stand out in invites.

## Frequently asked questions
### Is the Discord name generator free?
Yes. It's free, runs in your browser and doesn't require an account. Nothing you type is uploaded.

### What characters can a Discord username have?
At the time of writing, lowercase letters, numbers, underscores and periods, between 2 and 32 characters. Capitals, spaces and emoji belong in your display name instead.

### What's the difference between a Discord username and display name?
Your username is unique and used for friend requests. Your display name is what most people see in chats, and you can set a different nickname in each server.

### Does the generator check if a username or server name is taken?
No. Discord checks usernames when you try to change yours. Server names don't have to be unique, so any idea you like can be used for a server.

### Can I use fancy fonts in Discord names?
Not in usernames. Display names and server names accept many Unicode characters, but they can be hard to search for and screen readers may read them letter by letter. Try the [Discord font generator](/tools/discord-font-generator) for styled text in messages and About Me instead.

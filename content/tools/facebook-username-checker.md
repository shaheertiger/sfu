## Facebook Username Rules at a Glance

![Illustration for the free Facebook Username Checker: Facebook Username Checker, shown as 5–50 characters.](/images/tools/facebook-username-checker-hero-1200x675.webp)

A Facebook username has to be 5 to 50 characters long and can only use letters, numbers and periods. It can't start or end with a period or have two periods in a row. This Facebook username checker tests a name against those rules as you type. When it passes, a button opens facebook.com/yourname so you can see whether a profile or Page already uses it.

## Facebook Username Rules in Detail (5–50 Characters)
### Length: 5 to 50 characters
Facebook needs at least 5 characters, more than most platforms, and allows up to 50. The checker shows the length as a count out of 50. A four-letter name fails with "Too short: Facebook needs at least 5 characters," which rules out the short handles you might use on X or Pinterest.

### Letters, numbers and periods only
The period is the only symbol Facebook allows. Underscores, hyphens, apostrophes, ampersands, emoji and accented letters fail with "Only letters, numbers and periods are allowed." That's the opposite of X and Pinterest, which allow underscores but not periods, so riverside_bakery has to become riverside.bakery or riversidebakery here.

### No period at the start or end
A period is fine in the middle of a name, but not as the first or last character. .riverside fails with "It can't start with a period," and riverside. fails with "It can't end with a period."

### No two periods in a row
riverside..bakery fails with "Two periods in a row aren't allowed." Several single periods in different places are fine as far as the format goes.

### Periods and capitals don't count toward uniqueness
At the time of writing, Facebook's help pages say periods and capital letters aren't part of what makes a username unique. That means Riverside.Bakery, riverside.bakery and riversidebakery count as the same name. The checker doesn't apply this rule, so when you check whether a name is taken, try the version without periods too.

### Words Facebook blocks
Facebook also refuses usernames with generic terms or web endings such as .com and .net, and names that impersonate someone else. Those rules aren't in the checker, because Facebook decides them case by case; its username form is the authority.

### Profiles and Pages
Both personal profiles and Facebook Pages can have a username, and both use the same facebook.com/yourname address. A Page can't take a username a profile already uses, or the other way round, so check the name against both. The rules above apply to both.

## What This Facebook Name Checker Does (and What It Can't)

![What This Facebook Name Checker Does, in 3 groups: It opens the facebook.com URL, It can't promise a name is free and It suggests close valid variations.](/images/tools/facebook-username-checker-what-this-facebook-name-1200x675.webp)

### It checks the format Facebook accepts
The checker removes a leading @ and spaces around the name, counts the characters, and lists every rule the name breaks. A valid name shows "Follows Facebook's rules"; an invalid one shows "Not allowed" with each reason.

### It opens the facebook.com URL
When a name passes, the checker shows an **Open facebook.com/…** button. If a profile or Page opens, the name is taken. If Facebook says the content isn't available, the name may be free, but that message can also mean the page is private or restricted, and Facebook may ask you to log in before showing anything.

### It can't promise a name is free
Facebook doesn't offer a public availability check. Deactivated accounts, restricted Pages and reserved names can hold a username even when nothing shows up. The username field in your profile or Page settings gives the final answer, and it tells you immediately whether the name is available.

### It suggests close valid variations
Whenever you type a name, the checker suggests up to 12 variations that already pass Facebook's rules, such as theriverside.bakery, riverside.bakeryhq, realriverside.bakery or riverside.bakery.co. Suggestions use lowercase letters, numbers and periods; underscores are left out because Facebook doesn't allow them. A name longer than 46 characters is shortened first so the additions still fit.

### It checks a whole list at once
Switch to **Check a list** and paste up to 200 names, one per line or separated by commas. Duplicates are dropped, each name shows whether it follows the rules or the first rule it breaks, and every valid name links to its facebook.com URL. A **Copy the valid ones** button copies only the names that pass.

### It adds a tip for names without letters
A name made only of numbers and periods, like 12345, is allowed by the format but hard to find and remember. The checker adds a tip to include at least one letter. The name still passes.

### It runs in your browser
Nothing you type is sent to a server or saved, and the button is an ordinary link to facebook.com. You don't sign in to anything.

## How to Check if a Facebook Username Is Available

![How to Check if a Facebook Username Is Available, in 4 steps: type the username you want, read the result, open the URL and check the version without periods.](/images/tools/facebook-username-checker-how-to-1200x675.webp)

1. **Type the username you want.** Paste it with or without the @; the checker removes it.
2. **Read the result.** "Follows Facebook's rules" means the format is valid. "Not allowed" tells you why, such as an underscore or a period at the end.
3. **Open the URL.** Tap the **Open facebook.com/…** button. A profile or Page means the name is taken.
4. **Check the version without periods.** Because periods don't count, riverside.bakery is taken if riversidebakery is. Type both and open both links.
5. **Try a variation if needed.** Pick one of the suggestions, or paste your shortlist into **Check a list** and open each link.
6. **Claim it in Facebook.** For a profile, open Settings and find the username setting (on many accounts it's in Accounts Center, under your profile). For a Page, switch to the Page and look for the username in the Page's settings or Edit info. Menu labels change between app versions. Facebook tells you whether the name is available as you type.

## Best Practices for Picking a Facebook Username

![Best Practices for Picking a Facebook Username: do match the name people already know, use periods only where they help, shorter is easier and think about the Page name too.](/images/tools/facebook-username-checker-best-practices-1200x675.webp)

### Match the name people already know
For a Page, the username should match the business name on your sign, website and other profiles. If you need a modifier, use the same one everywhere, like riversidebakery on X and riverside.bakery on Facebook.

### Use periods only where they help
Since periods don't count toward uniqueness, they're just for readability. One period between words (riverside.bakery) helps; several (river.side.bake.ry) make a name harder to type.

### Shorter is easier
Fifty characters is the limit, not the target. A username around 10 to 20 characters fits on a business card and is easy to type from a poster.

### Think about the Page name too
The Page name is the display name at the top of your Page and can have spaces. Need ideas? The [Facebook page name generator](/tools/facebook-page-name-generator) and the [Facebook name generator](/tools/facebook-name-generator) suggest options, and you can paste the ones you like into **Check a list** here as usernames.

### Know what the checker doesn't test
It follows Facebook's published format. It doesn't merge names that differ only by periods or capitals, can't see blocked generic words, and can't see names held by deactivated accounts or reserved by Facebook. Treat a pass plus an empty URL as "worth trying."

### Don't trust tools that ask for your login
No website can see Facebook's username database. A "checker" that asks for your Facebook password or a login code is trying to take over your account. This tool never asks you to sign in.

## Frequently asked questions
### Can this checker tell me if a Facebook username is taken?
Not with certainty. It checks the name against Facebook's rules and opens the facebook.com URL so you can see whether a profile or Page uses it. The username field in your profile or Page settings gives the final answer.

### How many characters can a Facebook username have?
A Facebook username can have 5 to 50 characters at the time of writing, using letters, numbers and periods.

### Can a Facebook username have an underscore or a hyphen?
No. Only letters, numbers and periods are allowed. Use a period between words, or leave the separator out.

### Do periods matter in a Facebook username?
No, not for uniqueness. Facebook's help pages say periods and capitals aren't part of the username, so riverside.bakery and RiversideBakery count as the same name.

### Can a Facebook Page and a profile have the same username?
No. Profiles and Pages share the same facebook.com addresses, so a username used by one can't be used by the other.

### Why does Facebook say a name is taken when the link shows nothing?
The name may belong to a deactivated profile, a restricted or unpublished Page, or a name Facebook reserves. The link can also look empty if Facebook asks you to log in first.

### Can I check several Facebook usernames at once?
Yes. Switch to **Check a list** and paste up to 200 names. The checker marks which follow Facebook's rules, links each valid one to its URL, and copies the valid ones.

### Does the checker save the names I type?
No. It runs in your browser and nothing is uploaded or stored.

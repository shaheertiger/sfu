## Minecraft username rules at a glance
A Minecraft Java Edition username has to be 3 to 16 characters long and can only use letters, numbers and underscores. This Minecraft name availability checker tests a name against those rules as you type and, when it passes, gives you a button that searches NameMC, a third-party lookup site, so you can see whether a player already has it.

| Rule | What Minecraft allows (at the time of writing) | Checked here |
|---|---|---|
| Length | 3–16 characters | Yes |
| Characters | Letters A–Z, numbers 0–9 and underscores | Yes |
| Spaces | Not allowed | Yes |
| Periods, hyphens, emoji, accents | Not allowed | Yes |
| Capital letters | Allowed, but Steve and steve count as the same name | Shown as typed |
| Already taken | Can't be claimed | NameMC search only |

## What this Minecraft username checker does (and what it can't)
The checker answers the part you can answer on your own: is this a name Minecraft accepts? It removes spaces around the name (and a leading @, if you paste one), counts the characters, and lists every rule the name breaks in plain words, such as "Too long: 18 characters, the limit is 16."

It can't confirm that a name is free. Mojang and Microsoft don't offer a public availability checker, so no website can give you a guaranteed answer. What this tool does instead is link a valid name to a NameMC search. **NameMC is a third-party site. It isn't run by Minecraft, Mojang or Microsoft.** It lists Java Edition profiles that use a name, and often the names a profile used before. If a profile with your exact name shows up, the name is almost certainly taken. If nothing shows up, the name is worth trying, and the name change screen in your Minecraft account gives the final answer.

Everything runs in your browser. The names you type aren't sent to us or stored, and the NameMC button is a normal link that opens their search in a new tab.

## What the Minecraft name checker tests
### Length: 3 to 16 characters
Java Edition names need at least 3 characters and can't go past 16. The checker shows the length as a count out of 16 so you know how much you need to trim. Three-letter names are valid but almost all of them were claimed long ago.

### Letters, numbers and underscores only
The underscore is the only symbol allowed. Hyphens, periods, spaces, emoji and accented letters such as é fail the check with "Only letters, numbers and underscores are allowed." Block-Builder becomes Block_Builder or BlockBuilder.

### No spaces
A space anywhere fails the check. If you want two words, join them with an underscore or use capitals, like Block_Builder or BlockBuilder.

### Tips for names with no letters
A name made only of numbers and underscores, such as 2012_2012, is valid but hard for friends to remember or type into a server whitelist. The checker adds a tip suggesting at least one letter. The name still passes, because the tip is advice, not a rule.

### Close valid variations
When you type a name, the checker suggests up to 12 variations that already pass the rules, such as steve_, itssteve, realsteve, stevehq or stevelive. They're in lowercase; you can add capitals when you claim the name, because Minecraft keeps the capitals you choose. If your name is longer than 12 characters, it's shortened first so the additions still fit within 16.

### Check a list of names
Switch to **Check a list** and paste up to 200 names, one per line or separated by commas. Duplicates are dropped, each name shows whether it follows the rules or the first rule it breaks, and every valid name links to its NameMC search. A button copies only the valid ones.

### What the NameMC button shows
NameMC searches its own record of Java profiles. A profile with your exact name usually means it's taken. Because NameMC is a separate site, its data can lag behind Minecraft's, and it can't see every reason a name is blocked. Treat a missing profile as "worth trying," not "yours."

## How to check if a Minecraft username is taken
1. **Type the name you want.** Capitals are fine; the checker shows the name exactly as you typed it.
2. **Read the result.** "Follows Minecraft's rules" means the format is valid. "Not allowed" comes with the reason, such as a hyphen or a 17th character.
3. **Search NameMC.** Tap the **Open namemc.com/search…** button. Look for a profile with exactly your name, ignoring capitals.
4. **Try a variation if needed.** Pick one of the suggestions, or paste your shortlist into **Check a list** and open each NameMC link.
5. **Claim it in your account.** Sign in to your Minecraft account on the official Minecraft website or launcher and open the profile name settings (labels change between versions). Minecraft tells you whether the name is available when you try to save it. That's the only definitive check.

## Java Edition vs. Bedrock Edition names
### Java Edition
Java Edition uses a Minecraft profile name with the rules above: 3–16 characters, letters, numbers and underscores. It's the name that appears in chat, on the server player list and in commands such as /whitelist add. NameMC covers Java profiles, which is why the checker uses it.

### Bedrock Edition
Bedrock Edition (consoles, phones, Windows) shows your Xbox gamertag from your Microsoft account. Gamertags have their own rules and their own availability check in your Microsoft account settings, so this checker and NameMC don't apply to them.

## Best practices for picking a Minecraft username
### Keep it readable in chat
Names show up in small text in chat and above players' heads. Short, pronounceable names are easier for friends to type into /msg or a whitelist. Too many underscores and numbers make that harder.

### Avoid personal details
Your username is public on every server you join and on sites like NameMC. Leave out your real full name, birth year, school or town.

### Watch for lookalike letters
Capital I and lowercase l look alike in Minecraft's font, as do O and 0. A name that mixes them is easy to mistype and easy for someone else to copy.

### Never give your login to a "checker"
A username checker never needs your Microsoft password, an account code or a login. Sites that ask for them, or promise rare names or free accounts, are trying to steal accounts. This tool works without signing in to anything, and NameMC doesn't need your login to search either.

## Frequently asked questions
### Can this checker tell me if a Minecraft name is taken?
Not with certainty. It checks the name against Minecraft's rules and searches NameMC, a third-party site, for profiles that use it. The name change screen in your Minecraft account gives the final answer.

### Is NameMC an official Minecraft site?
No. NameMC is run independently and isn't part of Minecraft, Mojang or Microsoft. It's a public lookup site for Java profiles, and you don't need to sign in to use its search.

### How many characters can a Minecraft username have?
A Java Edition username can have 3 to 16 characters at the time of writing, using letters, numbers and underscores.

### Can a Minecraft username have spaces or a hyphen?
No. Only letters, numbers and underscores are allowed. Use an underscore or capitals to separate words, like Block_Builder or BlockBuilder.

### Are Minecraft usernames case-sensitive?
No. You can choose how the capitals appear, but Steve and steve count as the same name, so you can't register one if the other exists.

### Does this work for Bedrock Edition gamertags?
No. Bedrock Edition uses your Xbox gamertag, which has different rules and is checked in your Microsoft account settings. This checker covers Java Edition names.

### Can I check several Minecraft names at once?
Yes. Switch to **Check a list** and paste up to 200 names. It marks which follow the rules, links each valid one to a NameMC search, and copies the valid ones for you.

### Does the checker save the names I type?
No. It runs in your browser and nothing is uploaded or stored.

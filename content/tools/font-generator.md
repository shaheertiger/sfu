### How it works

Unicode, the standard that lets every device show the same text, includes thousands of characters beyond the basic alphabet. One block, Mathematical Alphanumeric Symbols, contains complete bold, italic, script, gothic, double-struck, sans-serif and monospace alphabets meant for math notation. Others contain circled, squared and fullwidth letters, and combining marks that draw a line through or under the previous character. The generator maps each letter you type to its look-alike.

### Why it isn't really a font

A font changes how the same letters are drawn. This tool changes which characters you're sending. That's why the style survives copy and paste, and also why search, spell check and screen readers don't treat it as normal text.

### Places styled text usually fails

Usernames and handles on most networks only allow plain letters, numbers and a few symbols. Hashtags and @mentions stop working when styled. Email addresses, URLs, passwords and form fields that validate input will reject or break on these characters.

### Places with better options

Discord and Telegram support real bold and italic in messages. Story and video editors on Instagram and TikTok have their own fonts. Word processors, design tools and websites can use actual font files. Reach for Unicode only where those aren't available.

## Best practices

### Style a few words, not everything

One styled headline or label draws the eye. A fully styled paragraph is tiring to read and loses the effect.

### Keep keywords and names searchable

Platform search reads the actual characters. Write product names, topics and anything you want to be found for in plain text.

### Consider accessibility

Screen readers may read styled characters one by one, call them math symbols, or skip them entirely. Don't put essential details like dates, prices or instructions only in a styled form.

### Test on more than one device

Support varies by operating system and installed fonts. Bold and italic are safest; squared, bubble and some script letters may show as boxes on older phones.

## Frequently asked questions

### Is this font generator free?

Yes. It's completely free, works in your browser without an account, and doesn't send what you type to any server.

### Can I install these fonts on my computer?

No. They aren't font files. They're Unicode characters you copy and paste. If you want a new font in a document or design app, you'll need to download an actual font file from a font provider.

### Why does the text look different on another phone?

Each device draws these characters with its own fonts, so the shapes vary slightly, and some characters may be missing entirely and show as boxes.

### Do styled letters count as more characters?

Often, yes. Many styled letters take two code units instead of one, so apps with strict limits may count them as two. Check with a counter such as the [X character counter](/tools/x-character-counter) before posting near a limit.

### Can I use these styles in emails or documents?

You can paste them, but email clients and documents support real formatting, which is more accessible and searchable. Use bold or italic buttons there instead.

### Is it allowed to use fancy text on social media?

Generally, yes, but platforms restrict it in certain fields, like legal names on Facebook or usernames almost everywhere. Never use styled text to impersonate someone or to get around content filters.

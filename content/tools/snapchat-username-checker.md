## Snapchat username rules at a glance
A Snapchat username has to be 3 to 15 characters long, start with a letter, end with a letter or number, and use only letters, numbers, hyphens, underscores and at most one period. This Snapchat username checker tests a name against all of those rules as you type and, when it passes, gives you a button that opens snapchat.com/add/yourname so you can see whether a profile already uses it.

## What this Snapchat name checker does (and what it can't)
The checker tells you whether a username follows the format Snapchat accepts. It removes spaces around the name and a leading @ if you paste one, counts the characters, and lists every rule the name breaks, such as "It has to start with a letter" or "Only one period is allowed."

It can't tell you for certain that a name is free. Snapchat doesn't offer a public availability check, and deleted, locked or banned accounts can hold a name even when nothing shows up for it. What you get is a one-tap link to the name's public Snapchat page. If a profile opens, the name is taken. If Snapchat says it can't find the user, the name is worth trying, and Snapchat's sign-up screen or the username setting in the app gives the final answer.

Everything runs in your browser. Nothing you type is sent to a server or saved, and the profile button is an ordinary link to snapchat.com.

## What the Snapchat username checker tests
### Length: 3 to 15 characters
Snapchat usernames are short: 15 characters at most and 3 at least. The checker shows a count out of 15, so you can see how much to trim. A 20-character Instagram handle won't carry over as it is.

### Allowed characters
Letters, numbers, hyphens, underscores and periods are allowed. Spaces, emoji, accented letters and other symbols such as & or ! fail with "Only letters, numbers, hyphens, underscores and one period are allowed." Snapchat shows usernames in lowercase, so capitals don't make a name unique.

### Only one period
Snapchat allows a single period. sunny.days passes; sunny.day.s fails with "Only one period is allowed." If you want more separation, use a hyphen or underscore for the second break, like sunny.days-uk.

### Must start with a letter
A username can't start with a number or a symbol. 1sunny and _sunny both fail with "It has to start with a letter." Move the number to the end instead: sunny1.

### Must end with a letter or number
A trailing hyphen, underscore or period isn't allowed. sunny_ fails with "It has to end with a letter or number." This is one of the most common reasons a Snapchat name is rejected, because adding an underscore at the end is the go-to trick on other platforms.

### Tips and close variations
If a name has no letters at all, the checker adds a tip to include one. Whenever you type a name, it also suggests up to 12 variations that pass every Snapchat rule, such as thesunny, itssunny, sunnyhq, sunny.co or realsunny. Suggestions only use letters, numbers, periods and underscores, so a hyphen in your name is dropped from them, and a name longer than 11 characters is shortened first so the additions still fit.

### Check a list of names
Switch to **Check a list** and paste up to 200 names, one per line or separated by commas. Duplicates are dropped, each name shows whether it follows the rules or the first rule it breaks, and every valid name links to its snapchat.com/add page. A button copies only the valid ones.

## How to check if a Snapchat username is available
1. **Type the username you want.** Leave out the @, or paste it with one; the checker removes it.
2. **Read the result.** "Follows Snapchat's rules" means the format is valid. "Not allowed" comes with each reason, so you can fix them all at once.
3. **Open the profile link.** Tap the **Open snapchat.com/add/…** button. The link uses your name in lowercase, the way Snapchat stores it. If a profile appears, the name is taken.
4. **Try a variation if needed.** Pick one of the suggestions, or paste a shortlist into **Check a list** and open each link.
5. **Claim it in the app.** On a new account, Snapchat asks for a username during sign-up and tells you right away if it's taken. On an existing account, open your profile, tap the settings gear and choose Username (menu labels change between app versions). Snapchat limits how often you can change your username, so check the name before you commit.

## Username vs. display name on Snapchat
### Username
Your username is unique, follows all the rules above, and is how people add you by search or by link (snapchat.com/add/yourname). It's the name this checker tests.

### Display name
Your display name is what friends see in chats and stories. It can have spaces, capitals and emoji, and it doesn't have to be unique, so there's nothing to check for availability. If the username you want is taken, you can still use the full name in your display name and pick a close variation for the username.

## Best practices for picking a Snapchat username
### Keep it easy to type from a sign or a story
People often add a Snapchat account by typing the name they saw somewhere else. Avoid mixing hyphens, underscores and the period in one name; one separator at most is easier to remember.

### Put the number at the end
Since a name can't start with a number, and a trailing symbol isn't allowed, a number at the very end (sunny7) is the simplest way to make a taken name unique.

### Leave out personal details
Your username is visible to anyone who has it or finds you in search. Skip your full name, birth year and school, especially for younger users.

### Don't trust tools that ask for your login
No website can see Snapchat's private list of usernames. A "checker" that asks for your Snapchat password or a code sent to your phone is trying to take over your account. This tool never asks you to sign in.

### Need ideas?

## Frequently asked questions
### Can this checker tell me if a Snapchat username is taken?
Not with certainty. It checks the name against Snapchat's rules and opens the public snapchat.com/add link so you can see whether a profile uses it. Snapchat's sign-up screen or the username setting in the app gives the final answer.

### How many characters can a Snapchat username have?
A Snapchat username can have 3 to 15 characters at the time of writing.

### Can a Snapchat username have a period?
Yes, but only one. Hyphens and underscores are also allowed, as long as the name doesn't end with one.

### Why can't my Snapchat username start with a number?
Snapchat requires every username to start with a letter. Put the number later in the name, like sunny7 instead of 7sunny.

### Can I use capital letters in a Snapchat username?
Snapchat shows usernames in lowercase, so capitals don't make a different name. Use your display name if you want capitals or spaces.

### Why does nothing show up, but Snapchat says the name is taken?
The name may belong to a deleted, locked or banned account, or Snapchat may reserve it. Those names can't be claimed even when no profile appears.

### Can I check several Snapchat names at once?
Yes. Switch to **Check a list** and paste up to 200 names. The checker marks which follow Snapchat's rules, links each valid one to its profile, and copies the valid ones.

### Does the checker save the names I type?
No. It runs in your browser and nothing is uploaded or stored.

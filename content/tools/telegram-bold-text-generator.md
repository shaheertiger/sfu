## How to bold text in Telegram messages

If you're writing a message or channel post, use Telegram's own formatting. It's real bold, so it stays searchable and accessible.

### On mobile

Type your message, select the words, and choose bold from the menu that appears. On some phones you'll find it under a "Formatting" option or the three-dot menu.

### On desktop

Select the text and press Ctrl+B (Cmd+B on Mac), or right-click and choose Formatting. Many desktop and web clients also convert `**double asterisks**` into bold as you send.

### In bots and automations

If you run a bot, the Telegram Bot API formats messages through a parse mode. With HTML you wrap text in `<b>` tags; with MarkdownV2 you use single asterisks. Unicode bold isn't needed for bot messages, but it is useful for button labels, which don't support formatting.

Inline and reply keyboard buttons display plain text only, so a bold label like "𝗦𝘂𝗯𝘀𝗰𝗿𝗶𝗯𝗲" can draw attention to the main action. Some people also style the names of their own chat folders, which only they will see.

## Best practices

### Prefer native bold whenever it exists

Inside messages, Unicode bold is the worse choice. Telegram's message search may not find styled words, and screen readers handle real formatting far better.

### Keep public titles searchable

Telegram's global search matches channel titles and usernames. Bold the decoration, not the topic: "𝗗𝗲𝗮𝗹𝘀 · Budget travel" is still findable for "budget travel."

### Don't impersonate

Bold names can make an account look official. Pretending to be a brand, admin or another person breaks Telegram's terms and misleads your members.

### Check the result in several clients

Telegram runs on many apps and devices. A style that looks fine on your phone may render as boxes on an older desktop, so check from a second device.

## Frequently asked questions

### What's the shortcut for bold on Telegram?

On desktop, select the text and press Ctrl+B, or Cmd+B on Mac. On mobile, select the text and pick bold from the formatting menu. Many apps also accept `**text**`.

### Can I make my Telegram name bold?

Yes. Copy a bold style from this generator and paste it into your first or last name in Settings. Your username can't use bold characters.

### Why isn't markdown bold working in my Telegram app?

Not every client converts markdown as you type. Use the formatting menu or keyboard shortcut instead, which work in all official apps.

### Can I bold a channel description?

Channel descriptions don't support formatting, but you can paste Unicode bold for a short label or two. Keep the rest plain so people can read and search it.

## Discord character limits at a glance
A regular Discord message can be up to 2,000 characters, or 4,000 if you have Nitro. Profile fields are much shorter. The counter checks the four fields people run into most and tells you how much room is left in each.

| Field | Limit | In the counter |
|---|---|---|
| Message | 2,000 characters (4,000 with Nitro) | Yes |
| About Me | 190 characters | Yes |
| Display name | 32 characters | Yes |
| Custom status | 128 characters | Yes |
| Username | 2–32 characters, lowercase letters, numbers, `_` and `.` | Reference only |
| Server name | 2–100 characters | Reference only |

### Messages
The 2,000-character cap applies to each message you send in a channel or DM. Nitro raises it to 4,000. If you're writing announcements or rules for a server, the lower limit is the one to plan around, because whoever posts the next update may not have Nitro.

### About Me and custom status
About Me is the short section on your profile card, capped at 190 characters. A custom status is the line under your name in the member list, capped at 128. For help wording a profile, see our guide to writing a [Discord bio](/blog/discord-bio).

### Display name vs. username
Your username is your unique account name and has strict character rules. Your display name is what people see in chat. It allows spaces, capitals and emoji, up to 32 characters.

## How Discord counts characters
Discord counts the text you actually send, which isn't always what you see on screen once a message renders.

### Markdown symbols count
Formatting like `**bold**`, `*italic*`, `~~strike~~` and backticks for `code` are typed characters, so they count toward the limit even though they disappear when the message is displayed. A code block wrapped in triple backticks adds at least six characters plus any language label.

### Mentions and custom emoji can cost more than they look
When you mention someone or a channel, or use a server's custom emoji, Discord stores a longer code behind the short name you see. That code is part of the message, so a message heavy with mentions and custom emoji can hit the limit sooner than the visible text suggests. The counter measures plain pasted text, so leave some headroom if you're using a lot of them.

### Line breaks and spaces count
Every space and every new line is a character. Long lists with blank lines between items eat into the budget faster than you might expect.

### What happens when you go over
Discord won't send a message that's over the limit. Depending on your app version, it may offer to send the text as a file attachment instead, which is harder for members to read on mobile.

## Best practices for Discord text
### Split long announcements on purpose
Rather than cramming a big update into one message, break it into a short headline message and a follow-up with details. Members who skim get the point, and you avoid the file-attachment fallback.

### Write rules and FAQs in short blocks
Server rules read better as a numbered list with one rule per line. If a rules post runs long, split it across a few messages in a read-only channel.

### Keep profile text readable
Fancy Unicode lettering can make an About Me stand out, but it often reads badly with screen readers and can push you over 190 characters faster. ## Frequently asked questions
### What is the Discord message character limit?
It's 2,000 characters per message, or 4,000 with Nitro. Messages over the limit can't be sent as normal text.

### How many characters is a Discord About Me?
The About Me section allows up to 190 characters, including spaces, emoji and line breaks.

### Does Discord markdown count toward the character limit?
Yes. Asterisks, tildes, backticks and other formatting symbols are counted even though they're hidden once the message renders.

### How long can a Discord display name be?
Display names can be up to 32 characters. Usernames are separate and must be 2–32 characters using lowercase letters, numbers, underscores and periods.

### What is the character limit for a Discord custom status?
A custom status can be up to 128 characters.

### Is my text sent anywhere when I use this counter?
No. The count happens in your browser and the text never leaves your device.

## How the Discord username checker works
This Discord username checker tells you whether a name follows Discord's username rules: 2 to 32 characters, lowercase letters, numbers, underscores and periods, and no two periods in a row. It **can't** tell you whether the name is free. Discord has no public profile page you can open by username and no public availability lookup, so the only real test is typing the name into Discord under User Settings → My Account → Username.

### What it checks
- Length between 2 and 32 characters
- Only lowercase letters a–z, numbers, underscores and periods
- No spaces, hyphens, emoji or other symbols
- No two periods in a row ("night..owl" fails, "night.owl" passes)

Capital letters aren't treated as an error. Discord stores usernames in lowercase, so the checker converts what you type and shows the name the way it will actually look. The checker also flags names made only of numbers and symbols, since a name with no letters is hard for friends to find and remember.

### What happens when a name fails
The result names the rule that failed in plain words, such as "Two periods in a row aren't allowed" or "Too long: 35 characters, the limit is 32," and shows the length against the 32-character limit. Below that you get close variations that already pass every rule, so you can pick one and go straight to testing it in Discord.

### Why there's no profile button
Most username checkers can link to a profile URL so you can see whether an account exists. Discord profiles aren't reachable at a public web address built from the username, so the checker doesn't pretend to look one up. Once a name passes, it tells you where to try it in the app instead.

### Nothing leaves your browser
The check runs on your device. The names you type aren't sent to Discord, to us or anywhere else, and nothing is saved.

Some tools and scripts claim to check hundreds of Discord usernames against Discord's servers. They usually need your account token or password to do it. Never paste either one into a third-party site or script: anyone holding your token can sign in as you. Discord's own settings screen is the only availability check you need.

## Discord username rules in detail
### Username vs. display name vs. server nickname
Discord gives you three names, and only one of them has strict rules.

- **Username:** your unique, lowercase name, such as night.owl. It's what friends type to add you, and no one else can have it at the same time. This is what the checker tests.
- **Display name:** the name shown in chats and on your profile. It can have capitals, spaces and emoji, and it doesn't have to be unique.
- **Server nickname:** an optional name you set per server, so you can be "Owl" in one community and "Owl (mod)" in another. Server admins can also change it.

If you want fancy lettering, put it in your display name or a nickname. Unicode styles from the [Discord font generator](/tools/discord-font-generator) work there, but they'll fail the username rules.

### What happened to the #1234 tags
Discord used to let many people share the same name by adding a four-digit tag, like owl#4821. Discord moved to unique usernames in 2023, which is why a short, common name is now hard to get: the old system had room for thousands of "owl"s, the new one has room for one.

### Periods and underscores
Both are allowed anywhere in the name, and underscores can repeat. The one restriction the checker enforces is no two periods in a row. Hyphens aren't allowed, so "night-owl" needs to become "night_owl" or "night.owl."

Open Discord, go to User Settings (the gear icon on desktop), choose My Account, then edit Username. Type the name and Discord tells you whether it's available. ## Frequently asked questions
### Can this checker tell me if a Discord username is taken?
No. It checks the name against Discord's format rules, but Discord has no public availability lookup and no profile URL by username. Try the name under User Settings → My Account → Username: Discord tells you there whether it's free.

### Can I check a list of Discord usernames at once?
Yes, for the rules. Check a list mode takes up to 200 names, one per line or comma separated, and shows which ones follow Discord's rules. It doesn't check availability for any of them.

### How long can a Discord username be?
Between 2 and 32 characters, using lowercase letters, numbers, underscores and periods.

### Can a Discord username have capital letters or spaces?
Not in the username itself. Discord stores usernames in lowercase and doesn't allow spaces. Your display name can have both, plus emoji.

### Do Discord usernames still have a # number?
Not for regular accounts. Discord moved to unique usernames in 2023, so the old name#1234 format has been replaced by a single lowercase username.

### Why does Discord say a username is taken when I can't find anyone using it?
You can't browse Discord accounts by username, so a name can be held by an account you'd never see, including inactive ones. The settings screen is the only place that knows.

### Does the checker store the names I type?
No. Everything runs in your browser and nothing is uploaded or saved.

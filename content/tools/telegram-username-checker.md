## What this Telegram username availability checker can tell you
This Telegram username availability checker does two things: it tests a name against Telegram's username rules (5 to 32 characters, letters, numbers and underscores, starting with a letter and not ending with an underscore), and it opens t.me/yourname so you can see whether something already uses it. It **can't** guarantee a name is free. Telegram has no public availability lookup, and some names are held by accounts or chats you can't see. The username field in Telegram's settings has the final word.

### The rules it tests
- Length between 5 and 32 characters
- Only letters a–z, numbers and underscores
- No spaces, periods, hyphens or emoji
- Starts with a letter
- Doesn't end with an underscore

Telegram usernames aren't case-sensitive: "MarketNotes" and "marketnotes" are the same name, so changing the capitals won't get you around a taken one. When a name fails, the checker names the rule it broke and suggests close variations that pass every rule.

### What the t.me link shows
Every Telegram username has a public link at t.me/ followed by the name. When the name is taken, that page shows a preview of the profile, channel, group or bot with an "open in Telegram" button. When it isn't, you get a generic Telegram page with no one's name on it. That's a strong hint the name is open, but not proof: at the time of writing, some names are reserved or held as collectibles, and those can be unavailable even when the link shows nothing useful.

### It runs in your browser
Nothing you type is sent to Telegram or to us, and nothing is stored. The t.me button is an ordinary link.

## How to check a Telegram username
### 1. Type the name you want
Enter it without the @. If you'd normally separate words with a space, hyphen or period, use an underscore instead: "market_notes," not "market-notes."

### 2. Fix what's flagged
The most common problems are a name under five characters, a name that starts with a number ("1stmarket"), and a trailing underscore. The checker tells you which one applies.

### 3. Open the t.me link
If a profile, channel or bot preview appears, the name is taken. If not, move on to the app.

### 4. Confirm in Telegram
Open Telegram, go to Settings, edit your profile and tap Username. Telegram checks the name as you type and tells you whether you can use it. At the time of writing, the exact menu labels vary a little between the phone, desktop and web apps.

### Checking a list
Switch to **Check a list** to paste up to 200 ideas, one per line. The checker marks which ones follow Telegram's rules, links each valid one to its t.me page and lets you copy just the valid names.

## Usernames for accounts, channels, groups and bots
### One shared pool of names
Personal accounts, public channels, public groups and bots all draw usernames from the same pool. A channel called t.me/marketnotes means no personal account or bot can be @marketnotes. If the name you want is taken, the t.me preview shows you what kind of chat holds it.

### Personal accounts
A username is optional on a personal account. Without one, people mostly find you by phone number or through shared groups; with one, they can message you at t.me/yourname without seeing your number. Your first and last name are separate from the username and can include spaces and emoji.

### Public channels and groups
A channel or group becomes public when you give it a username, which becomes its t.me link. You set it in the channel or group settings by switching its type to public. Keep it short and close to the channel's name so people can type it from a screenshot.

### Bots
Bot usernames follow the same rules with one addition: they must end in "bot," such as weather_bot or WeatherBot. You choose it when you create the bot with BotFather. This checker tests the general username rules only, so add the "bot" ending yourself before you check a bot name.

## Frequently asked questions
### Can this checker tell me if a Telegram username is available?
Not for certain. It checks the format and opens the t.me link so you can see whether something uses the name, but Telegram has no public availability lookup. The username field in Telegram's settings gives the definite answer.

### How long does a Telegram username have to be?
Between 5 and 32 characters, using letters, numbers and underscores. It has to start with a letter and can't end with an underscore.

### Are Telegram usernames case-sensitive?
No. Telegram treats capital and lowercase letters as the same, so "MarketNotes" and "marketnotes" are one username.

### Why does the t.me link show nothing but Telegram says the name is taken?
Some names are reserved or held in ways a t.me page doesn't reveal, including collectible usernames at the time of writing. If the settings field says it's taken, try a close variation.

### Can a channel and a personal account have the same username?
No. Accounts, channels, groups and bots share one pool of usernames, so each name can only belong to one of them at a time.

### What are the rules for a Telegram bot username?
The same as for any username, plus it must end in "bot," for example weather_bot. You set it when creating the bot with BotFather.

### Does the checker save the names I type?
No. Everything runs in your browser and nothing is uploaded or stored.

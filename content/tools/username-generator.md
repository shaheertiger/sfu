## What the Username Generator Does
The username generator is a username maker built from templates and word lists, not from a language model. It takes the word you type, combines it with the word bank for the style you chose (prefixes, endings and a few style-specific numbers) in patterns like `prefix + word`, `word + ending`, `word_ending` and `prefix_word_ending`, then throws away anything that breaks the rules. You get the first 30 that pass, shuffled.

### What it does with what you type
- **Up to three words:** "night owl" or "green tea club" works; anything after the third word is ignored.
- **Accents and symbols removed:** "Zoë" becomes zoe, and punctuation splits words.
- **Lowercase only:** capitals are lowered so every result is valid on platforms that don't allow them.
- **Hyphens become underscores:** the Funny style's "part-time" turns into part_time.
- **An empty box isn't a problem:** with nothing typed, it uses a placeholder word so you can see how each style works.

### The rule set behind every idea
Each idea is 3–15 characters long and uses only lowercase letters, numbers and underscores. That's tight on purpose: 15 is X's maximum, and periods, hyphens and capital letters are each rejected by at least one major platform. The cost is that a few ideas will be too short for Telegram, which needs at least 5 characters, a few have two underscores, which Roblox doesn't allow, and some longer favourites won't appear at all.

### More ideas
**More ideas** reshuffles the word bank and builds a new set of 30 for the same word and style. Results are repeatable: the same word, style and click count give the same list, so you can come back to an idea you saw earlier.

### What it doesn't do
It doesn't check whether a username is taken. No generator can do that reliably for every platform. Once you have a shortlist, run it through the [username checker](/tools/username-checker), which tests each name against each platform's format rules and opens the profile link so you can see whether an account already uses it.

### X: the strictest length
X's 15-character ceiling is why this generator stops at 15. If you'll never use X, the platform generators below allow longer names.

### Instagram, TikTok and Discord: periods allowed
These three accept periods, so you can turn `velvet_luna` into `velvet.luna` if you prefer the look. Just remember the period version won't work on X, Reddit, Telegram or Roblox. For Instagram-only ideas, use the [Instagram name generator](/tools/instagram-name-generator); for TikTok, the [TikTok name generator](/tools/tiktok-name-generator).

### Telegram: the 5-character minimum
Telegram usernames must be at least 5 characters, start with a letter and not end with an underscore. Skip the very short ideas if Telegram is on your list, avoid starting your word with a number, or use the [Telegram name generator](/tools/telegram-name-generator).

### Roblox: one underscore
Roblox allows only one underscore, and not at the start or end. Most results have one underscore or none, but the `prefix_word_ending` pattern produces names with two, such as `part_time_jake`. Drop one underscore (`parttime_jake`) or pick another idea. The [Roblox username checker](/tools/roblox-username-checker) confirms the format.

### YouTube: a handle and a name
YouTube has both a channel name, which can contain spaces, and an @handle, which follows the rules in the table. Any username from this generator works as a handle. For a channel name with spaces, try the [YouTube name generator](/tools/youtube-name-generator).

## Username Best Practices

![Username Best Practices: do say it out loud once, choose numbers on purpose and one name, everywhere. Avoid personal details and don't copy someone else's name.](/images/tools/username-generator-best-practices-1200x675.webp)

### Say it out loud once
If you have to spell it, it's too complicated. A name you can say once and have someone type correctly is worth more than a clever one with three underscores.

### Avoid personal details
Your birth year, full name, school or town make you easier to find and can date you. "maya2009" tells strangers more than you mean to.

### Choose numbers on purpose
A number that's part of the joke (`chef404`) or the vibe (`frostnova360`) is fine. Random digits added only because the name was taken look like a placeholder. Try a different ending first.

### One name, everywhere
Consistency makes you findable. If someone sees `studio_maya` on TikTok, they'll search for exactly that on Instagram. Claim the name on every platform you might use, even ones you're not active on yet.

### Don't copy someone else's name
Variations of a well-known creator's or brand's name can get your account reported for impersonation or trademark issues. Build from your own word.

### Think about changing it later
Some platforms limit how often you can change your username, and Reddit doesn't let you change it at all. Old links and tags stop pointing to you when you change. Choose something you'll be happy with in a few years, not just this month.

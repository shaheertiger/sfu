You've written the perfect Bluesky post and the counter has gone red. The Bluesky character limit is **300 characters** per post, counted in graphemes, so an emoji counts as one. Anything longer has to become a thread, where each reply gets its own 300 characters.

![Bluesky character limit: 300 characters per post, counted in graphemes, with up to four images or one video](/images/blog/bluesky-character-limit-hero-1200x675.webp)

The number is easy. What trips people up is how it's counted: emoji count differently than on X, links can count as their shortened text in the app, and media has its own set of limits.

This guide covers every Bluesky limit in one table, how links, mentions and hashtags count, how to write a thread that reads well, and how to schedule Bluesky posts when the app has no scheduler of its own.

## Why Bluesky Counts Characters Differently (Graphemes, Not Bytes)

Bluesky counts **graphemes**: the characters you'd count by eye. A family emoji built from several code points still counts as one, and so does an accented letter. That's why an emoji-heavy post fits more easily on Bluesky than on X, where most emoji count as 2.

![Bluesky counts what you see, while some other platforms count hidden code points](/images/blog/bluesky-character-limit-graphemes-1200x675.webp)

### What Most People Don't Know

The limit is set by the Bluesky app and the AT Protocol, not by your keyboard, so different apps can show slightly different counts. And in the official app, a link shows as a shortened version (the domain plus a few characters), and that shortened text is what counts. A post with one long link usually keeps 270 or more characters for text.

> **Key point:** 300 is the hard ceiling for one post. If you need more, don't cut the meaning out: split it into a thread, where each part gets its own 300 characters.

## How Links, Mentions and Hashtags Count Toward 300

| Element | How it counts | Example |
|---|---|---|
| Plain text and emoji | Each visible character is 1 | "Hi 👋" is 4 |
| Links (in the Bluesky app) | The shortened text Bluesky shows, not the full address | A long article URL counts as its short preview |
| Mentions | The handle text you type | `@maya.bsky.social` is 17 |
| Hashtags | In full, including the `#` | `#photography` is 12 |
| Line breaks | Count as characters | A blank line between paragraphs uses some of your 300 |

One caution about links: the shortening happens in the app you post from. Some tools that post through Bluesky's API count the full address you paste, so a long tracking link can eat most of your post. If space is tight, use a clean, short URL.

Need a quick count before you post? Paste your text into the free [X character counter](/tools/x-character-counter) as a rough check. It counts X's way, so emoji count as 2 there, which means text it passes will fit Bluesky's 300 too. Links are the exception, because X counts every link as 23 characters.

## How to Write a Bluesky Thread for Posts Over 300 Characters

Anything longer than 300 characters is a thread. Each reply is its own 300-character post, and media goes on whichever post you attach it to.

![Four steps to turn a long Bluesky post into a thread that reads well](/images/blog/bluesky-character-limit-thread-1200x675.webp)

### Step 1: Write the Whole Thing First

Draft the full text without worrying about the limit. You'll split it later, and splitting a finished piece reads better than writing in 300-character bursts.

### Step 2: Make the First Post Stand on Its Own

This is the step people get wrong. Readers see only the first post in the feed and open the thread for the rest, so the first post needs the hook and the main point, not "A thread 🧵 (1/7)".

### Step 3: Split at Natural Breaks

End each post on a complete sentence. Don't break mid-sentence just to fill every character.

### Step 4: Put Media Where It Helps

Attach images or video to the post they illustrate. A chart belongs with the sentence that explains it.

> **Pro tip:** Read the thread as if you'd only seen the first post. If it doesn't make you want to tap, rewrite it before you split the rest.

## Bluesky vs X vs Threads: Character Limits Compared

If you post the same idea everywhere, the limits decide how much you need to rewrite.

![Character limits on Bluesky, X and Threads compared](/images/blog/bluesky-character-limit-compare-1200x675.webp)

| Platform | Post limit | Emoji | Longer posts |
|---|---|---|---|
| Bluesky | 300 characters | Usually count as 1 | Threads of replies |
| X | 280 characters (without a paid subscription) | Most count as 2 | Threads, or longer posts with a paid subscription |
| Threads | 500 characters | Count as 1 | Threads of replies |

So a post written for Threads usually needs trimming for Bluesky, and a post that fits X will almost always fit Bluesky. See our guide to the [Threads character limit](/blog/threads-character-limit) for Meta's rules.

## Best Time to Post on Bluesky (and How Much)

Bluesky's audience skews toward the US and Europe and is most active on weekday mornings and evenings in those time zones, with the feed quieter at weekends. The Discover feed surfaces posts by engagement over the first hour or two, so post when your followers are online and reply to early comments.

Keep a steady rhythm: a few posts a day beats ten at once. For more on building an audience there, see [how to get followers on Bluesky](/blog/how-to-get-followers-on-bluesky).

## Schedule Bluesky Posts That Always Fit (Schedule For You)

Bluesky has no scheduling feature of its own at the time of writing. To schedule, you need a tool that connects with an **app password**, which you create in Bluesky under **Settings → Privacy and security → App passwords** (menu labels can change between app versions). An app password lets the tool post without your main password, and you can revoke it any time.

## Frequently Asked Questions

### What is the character limit on Bluesky?

The limit is 300 characters per post, counted in graphemes, so most emoji count as one. Longer text needs a thread.

### Do emoji count as one character on Bluesky?

Yes, usually. Bluesky counts graphemes, the characters you see, so even an emoji built from several code points counts as one.

### Do links count toward Bluesky's character limit?

Yes, but in the Bluesky app a link counts as the shortened text it displays, not the full address. Tools that post through the API may count the full link, so keep URLs short.

### Can you post videos on Bluesky?

Yes, one video per post. Since August 2026 a video can run up to 10 minutes and 300 MB; before that the cap was 3 minutes.

### How many images can a Bluesky post have?

A post can have up to 4 images. Since the April 2026 app update each can be up to 2 MB and 4,000 × 4,000 px.

### How long can Bluesky alt text be?

Alt text can be up to 2,000 characters per image, which is plenty for a full description.

### Does Bluesky have a scheduling feature?

No, not at the time of writing. Scheduling needs a third-party tool connected with an app password from Bluesky's settings.

### Is a Bluesky app password safe?

Yes. It's a separate password with posting permissions only, it can't change your account settings, and you can revoke it from Bluesky at any time.

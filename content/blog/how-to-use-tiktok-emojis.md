To use TikTok's secret emojis, type a code inside **square brackets** in a comment, for example **[smile]**, **[happy]** or **[cool]**, and TikTok swaps it for one of its own round, pink-faced emojis when you post. There's no emoji picker for them; you have to know the code. They work reliably in **comments**. In captions and bios they often stay as plain text, so treat comments as the place to use them.

Regular emojis from your phone keyboard work everywhere on TikTok: comments, captions, bio, display name and on-screen text.

## How to type a TikTok emoji code

1. Open a video and tap the **comment** icon.
2. Type an open square bracket **[**. On iPhone it's on the symbols keyboard (tap 123, then #+=); on Android it's on the symbols page.
3. Type the code in lowercase, such as **smile**.
4. Type a close bracket **]**.
5. Post the comment. The code turns into the emoji.

If the code shows as text after you post, it's either misspelled or not supported in your version of the app.

## Why your TikTok emoji code isn't working

- **You're in a caption or bio.** Codes convert in comments; elsewhere they often stay as text.
- **Typo or capital letters.** [Smile] and [ smile ] won't convert. Use [smile].
- **Wrong bracket.** Round ( ) or curly { } brackets don't work.
- **Old app or web version.** Update the app. The desktop site doesn't always render them.
- **The code was retired.** Lists online include codes that no longer exist.

## Frequently asked questions

### Can I use TikTok secret emojis in my caption?
Sometimes, but not reliably. They convert in comments; in captions they often show as plain text like [smile]. Use regular keyboard emojis in captions.

### Why are TikTok emojis pink?
They're TikTok's own designs, separate from Apple's or Google's emojis. TikTok drew them in its brand style, and they only appear inside the TikTok app.

### Can I use TikTok emojis on other apps?
No. The codes are converted by TikTok and only display inside TikTok. Pasted elsewhere, they're just text in brackets.

### How many secret emojis does TikTok have?
Around 46 according to most lists, though TikTok doesn't publish an official count and the set has changed over time.

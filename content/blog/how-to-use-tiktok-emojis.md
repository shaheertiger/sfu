You've seen those round, pink-faced emojis in TikTok comments and can't find them on your keyboard. To use TikTok's secret emojis, type a code inside **square brackets** in a comment, for example **[smile]**, **[happy]** or **[cool]**, and TikTok swaps it for one of its own emojis when you post.

![TikTok secret emojis: type a code like [smile] in square brackets in a comment and it turns into TikTok's own emoji](/images/blog/how-to-use-tiktok-emojis-hero-1200x675.webp)

There's no emoji picker for them; you have to know the code. And they work reliably in **comments** only. In captions and bios they often stay as plain text, which is why so many people think they're broken.

This guide covers how to type the codes, the full list of 46, why a code doesn't convert, and how to use regular emojis in captions.

## Why TikTok Hides Its Own Emojis (and Where They Work)

![Where TikTok emoji codes work: comments convert, captions, bios and other apps usually show plain text](/images/blog/how-to-use-tiktok-emojis-where-1200x675.webp)

TikTok's secret emojis are its own designs, drawn in its brand style and separate from Apple's or Google's emojis. TikTok converts the code into the image when it shows the comment, so they only appear inside TikTok.

| Comments | Converts to TikTok's emoji | Works |

| Display name | Stays as text | Works |
| On-screen text in a video | Stays as text | Works |
| Other apps | Stays as text | Works |

### What Most People Don't Know

The codes aren't emoji characters at all. They're plain text that TikTok recognises and replaces when it displays a comment. Copy one into Instagram or a message and you'll just see the brackets, because no other app knows to swap it.

> **Key point:** Use secret codes in comments and regular keyboard emojis everywhere else. That one rule explains almost every "it didn't work".

## How to Type a TikTok Emoji Code (5 Steps)

![Five steps to type a TikTok emoji code: open comments, type an open bracket, the code in lowercase, a close bracket, then post](/images/blog/how-to-use-tiktok-emojis-steps-1200x675.webp)

Keyboard layouts and menu labels change between phone and app versions, so look for the closest match.

### Step 1: Open the Comments

Open a video and tap the **comment** icon.

### Step 2: Type an Open Square Bracket [

On iPhone it's on the symbols keyboard (tap 123, then #+=); on Android it's on the symbols page.

### Step 3: Type the Code in Lowercase

For example, **smile**. No spaces and no capitals.

### Step 4: Type a Close Bracket ]

### Step 5: Post the Comment

The code turns into the emoji. If it shows as text after you post, it's either misspelled or not supported in your version of the app.

> **Pro tip:** Save your favourite codes in your phone's text replacement settings, so typing a shortcut like "ts" expands to [smile]. It saves hunting for brackets every time.

## How to Use Emojis in TikTok Captions That Convert

Captions are where keyboard emojis earn their place, as signposts rather than decoration:

- **One at the start of a line** to break up a list or steps.
- **One to signal tone**, so a joke reads as a joke.
- **Key words in text, not emoji**, because TikTok search reads words.
- **Not in place of hashtags**, which help TikTok understand your topic.

## Frequently Asked Questions

### Can I use TikTok secret emojis in my caption?

Sometimes, but not reliably. They convert in comments; in captions they often show as plain text like [smile]. Use regular keyboard emojis in captions.

### Why are TikTok emojis pink?

They're TikTok's own designs, separate from Apple's or Google's emojis. TikTok drew them in its brand style, and they only appear inside the TikTok app.

### Can I use TikTok emojis on other apps?

No. The codes are converted by TikTok and only display inside TikTok. Pasted elsewhere, they're just text in brackets.

### How many secret emojis does TikTok have?

Around 46 according to most lists, though TikTok doesn't publish an official count and the set has changed over time.

### Why does my TikTok emoji code show as text?

It's in a caption or bio, it has a typo or capital letter, it uses the wrong brackets, or the code has been retired.

### Do TikTok emoji codes work on the desktop website?

Not reliably. The desktop site doesn't always render them; check on your phone.

### Where are square brackets on my phone keyboard?

On iPhone, tap 123, then #+=. On Android, open the symbols page.

### Do emojis help TikTok captions get found?

Not on their own. TikTok search reads words, so keep key words in text and use emojis as signposts.
